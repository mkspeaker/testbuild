# структура проекта

в корне проекта есть три директории: opt, plugins, tmp, три файла: main.py, sonutils.py, config.json.

директория opt - необходимые для работы ядра и плагинов компоненты.

директория plugins - плагины

директория tmp - временные файлы, такие как сгенерированный голос, логи.

sonutils - это набор утилит для более простой разработки плагинов. с его помощью можно использовать tts, stt функционал, воспроизводить аудио файлы, использовать планировщик и логгер, использовать функцию определеиня пайплайна, преобразовывать текст.

config.json - файл конфигурации проекта. тут настраиваются ключи и ключевые фразы функций.

main.py - управляющий скрипт. сначала он парсит config.json. далее он осуществляет перенаправление фреймов звука из микрофона в wakeword модель, обрабатывает выходные значения. если значение удовлетворяет условию, то main.py вызывает stt функционал из модуля sonutils.полученный запрос отправляется в функцию распознавания намерений(intent recognition). эта функция определяет какой запускать плагин, используя конфигурацию из config.json. далее main.py вызывает пределенный плагин, передавая ему контекст запроса.

# функции sonutils

1. logger
зависимости: logging

логгер записывает логи в файл. в троку лога он записывает время записи, уровень лога, наименование исполняемого скрипта, функцию, в которой он был вызван, сообщение от функции об ошибке или об отладочной информации.

пример вызова из плагина:
``` python
import sonutils
def example():
	sonutils.logger.debug("отладочная информация")
	sonutils.logger.error("ошибка")
	try:
		a = ""/0
	except:
		sonutils.logger.exception() # вывод информации об ошибке
```

2. tts
зависимости: sounddevice, piper-tts, wave, модель для генерации голоса в директории opt.

принимает аргумент текстовый аргумент - text, синтезирует аудио и воспроизводит его.

рекомендации по использованию:
рекомендуется переводить текст в наиболее читабельный для нейросети, не использовать сокращения. все иноязычные слова, специальные символы, числа и тому подобное переводить в русскоязычный словесный формат. однако если рекомендации не будут соблюдены, то аудио все равно будет синтезировано и проиграно, но озвучка будет страдать
функция не асинхронная, выполняется до тех пор, пока аудио поток не будет проигран. функция не возвращает никаких значений.

пример использования:
``` python
import sonutils
sonutils.tts("свет в прихожей выключен")
```

3. stt
зависимости: sounddevice, vosk, signal, string, queue

принимает целочисленый аргумент - length - длина принятия голосового ввода в секундах, по умолчанию - 5.
аудио фреймы передаются в vosk, который формирует ответ. по истесении времени length, возвращается ответ.

рекомендации по использованию:
функция не асинхронная, выполняется length секундс погрешностью меньшее 0.5 секунд на инициализацию vosk.
текст возвращается строчными буквами без знаков препинания.

пример использования: 
``` python
import sonutils
query = sonutils.stt()
```

4. play_wav
зависимости: sounddevice, soundfile

принимает путь аудио файла в текстовом формате и проигрывает его.

рекомендации по использованию:
функция не асинхронная, выполняется до тех пор, пока проигрывается аудио файл.

пример использования:
``` python
import sonutils
sonutils.play_wav("opt/alarm_sound.wav")
```

8. scheduler
зависимости: datetime, importlib, spscheduler

принимает четыре аргумента: stype, timelist, plugin_name, message. 
stype - один из типов планирования: 'timer', 'scheduler', 'alarm'. 
timelist - список из трех значений - часы, минуты, секунды. 
plugin_name - имя запускаемого плагина. если плагин находится в папке, то имя записывается в формате `folder.plugin`. 
message - сообщение, которое необходимо передать в плагин, по умолчанию пустой.

timer прибавляет к текущему времени единицы из timelist, и выоплняет действие в в это время.
scheduler выполняет действие единажды в определенное время заданное в timelist.
alarm выполнит действие каждый день в определенное время заданное в timelist.
